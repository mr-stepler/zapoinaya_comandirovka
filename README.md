# ⚡ NeuroAPI — Единый шлюз API для всех нейросетей

Платформа для продажи и интеграции API передовых искусственных интеллектов и нейросетей: **OpenAI GPT-4o / o1 / o3-mini**, **Anthropic Claude 3.5 Sonnet / Haiku**, **DeepSeek V3 / R1**, **FLUX.1 Schnell & Dev**, **Midjourney v6.1**, **Whisper Large v3** и других.

---

## 🌟 Основные возможности

1. **Единый баланс и пополнение счета:**
   - Оплата в российских рублях без зарубежных карт и VPN.
   - Поддержка СБП (0% комиссии по QR-коду), банковских карт МИР/Visa/Mastercard, ЮMoney и криптовалюты (USDT TRC20, TON, BTC).
   - Бонусная система: кэшбэк на баланс до +15% при пополнении от 2 500 ₽.
   - Система промокодов (`NEURO2026`, `WELCOME100`, `DEV500`, `DUCKAI`, `STARTAI`).
   - Детальная история транзакций и списаний в реальном времени.

2. **Совместимость с OpenAI SDK:**
   - 100% drop-in замена официального API OpenAI.
   - Достаточно указать `base_url="https://api.neuroapi.io/v1"` и передать ключ `sk-neuro-...`.
   - Поддержка Python, Node.js/TypeScript, cURL, LangChain, LlamaIndex, aiogram ботов.

3. **Личный кабинет разработчика:**
   - Управление секретными API ключами с настройкой лимитов расходов.
   - Интерактивная **AI Песочница (Playground)** с выбором моделей, настройкой температуры, замером задержки (latency) и автоматическим списанием токенов с баланса.
   - Каталог моделей с фильтрацией по категориям (LLM, Reasoning, Генерация изображений, Кодинг, Аудио).
   - Документация и готовые сниппеты кода.

4. **Приветственный бонус:**
   - Каждому новому пользователю автоматически начисляется **150 ₽ на баланс** при регистрации для бесплатного тестирования любых нейросетей.

## 🚀 Запуск проекта

### 1. Установка зависимостей:
```bash
pip install flask mysql-connector-python
```

### 2. Запуск веб-сервера:
```bash
PYTHONPATH=src python3 src/duck/app.py
```
Сервер запустится на `http://0.0.0.0:5000`.
