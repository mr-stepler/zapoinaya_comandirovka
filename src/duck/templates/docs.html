🚀 1. Быстрый старт

Шлюз NeuroAPI на 100% аппаратно и программно совместим с протоколом OpenAI REST API. Чтобы перевести любой существующий проект или библиотеку (LangChain, LlamaIndex, AutoGen, CrewAI, Cursor) на NeuroAPI, достаточно изменить лишь Base URL и передать ваш ключ sk-neuro-....

Base URL: https://api.neuroapi.io/v1
Completions: https://api.neuroapi.io/v1/chat/completions

🔑 2. Авторизация запросов

Все HTTP запросы должны содержать заголовок Authorization: Bearer YOUR_API_KEY.

curl https://api.neuroapi.io/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer sk-neuro-98fa72bc91d842" \ -d '{ "model": "deepseek-chat-v3", "messages": [ {"role": "system", "content": "Ты полезный AI помощник."}, {"role": "user", "content": "Привет! Назови столицу Франции."} ], "temperature": 0.7 }'

🐍 3. Интеграция в Python (OpenAI SDK)

Установите стандартный пакет pip install openai и инициализируйте клиент с указанием шлюза NeuroAPI:

import openai # Инициализируем клиент client = openai.OpenAI( api_key="sk-neuro-ВАШ_КЛЮЧ_ИЗ_КАБИНЕТА", base_url="https://api.neuroapi.io/v1" ) # Отправляем запрос к DeepSeek V3, Claude 3.5 или GPT-4o response = client.chat.completions.create( model="claude-3-5-sonnet", # или deepseek-reasoner-r1, gpt-4o messages=[ {"role": "system", "content": "Ты старший Python-разработчик."}, {"role": "user", "content": "Напиши FastAPI эндпоинт с валидацией Pydantic."} ], temperature=0.5, max_tokens=1000 ) # Выводим ответ print(response.choices[0].message.content)

🤖 4. Пример Telegram-бота на aiogram 3.x

Готовый шаблон Telegram-бота, отвечающего на любые сообщения через нейросеть DeepSeek / GPT-4o:

import asyncio import openai from aiogram import Bot, Dispatcher, types from aiogram.filters import CommandStart TELEGRAM_TOKEN = "ВАШ_ТОКЕН_БОТА_ИЗ_BOTFATHER" NEURO_API_KEY = "sk-neuro-ВАШ_КЛЮЧ_NEUROAPI" bot = Bot(token=TELEGRAM_TOKEN) dp = Dispatcher() ai_client = openai.AsyncOpenAI( api_key=NEURO_API_KEY, base_url="https://api.neuroapi.io/v1" ) @dp.message(CommandStart()) async def cmd_start(message: types.Message): await message.answer("Привет! Я AI-ассистент на базе NeuroAPI. Задайте мне любой вопрос!") @dp.message() async def handle_ai_message(message: types.Message): await message.bot.send_chat_action(chat_id=message.chat.id, action="typing") try: response = await ai_client.chat.completions.create( model="deepseek-chat-v3", messages=[{"role": "user", "content": message.text}] ) await message.answer(response.choices[0].message.content) except Exception as e: await message.answer(f"Ошибка вызова AI: {str(e)}") async def main(): await dp.start_polling(bot) if __name__ == "__main__": asyncio.run(main())

⚠️ 5. Коды ошибок API

Код HTTP Название Причина и решение
200 OK Success Запрос успешно обработан, ответ сформирован.
401 Unauthorized Invalid API Key Неверный или отозванный ключ. Проверьте заголовок Authorization.
402 Insufficient Quota No Balance На балансе недостаточно средств. Пополните баланс в кабинете.
429 Too Many Requests Rate Limit Exceeded Превышен лимит запросов в минуту (RPM). Увеличьте интервал.
